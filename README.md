This repository fronts the complete maintained cumulative English edition of
the Emmy Noether mathematical corpus. “Complete” describes corpus coverage; it
does not claim that the text is defect-free, independently approved, or a
critical edition.

The edition is rebased through all 25 accepted corrections and geometry changes
in German authority `NOETH-DE-AUTH-v051-20260811` / `NOETH-DE-ED-0014`, source
SHA-256 `EE226847656BC4D65EDDA9E9BF9BB1D25797C0C6D672D267D94A97FD88C7AD58`. It remains a
machine-assisted working English translation and has not been independently
peer reviewed.

- `evidence/`: exact ED0014 rebase ledger/diff, source receipt, and final QA
